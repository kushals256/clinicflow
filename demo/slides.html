ClinicFlow Capstone2 / 16
01 · Project overview

Why ClinicFlow?

Clinics need a simple way to book visits, track priority/status, and operate the same app from a laptop to Kubernetes — with security and observability baked in.

Product goals

  • Book and manage patient appointments (CRUD)
  • Track priority (HIGH / MEDIUM / …) and status
  • Stats for a quick operational snapshot
  • Usable React UI + OpenAPI docs
  • Health / ready probes for orchestration

Capstone goals

  • Original domain (not a TaskBoard clone)
  • Prove M1–M10: app → tests → Git → Docker → CI → Trivy → Terraform → K8s → metrics → presentation
  • Immutable SHA-tagged images in GHCR
  • Real AWS VPC + EKS, then destroy for cost
  • Prometheus UP + Grafana live panels

04 · Architecture

End-to-end delivery path

Developer → GitHub → Actions (pytest · build · Trivy · push SHA) → GHCR images → Terraform (VPC + EKS) → Argo CD / Helm → Frontend + Backend → PostgreSQL → /metrics → Prometheus → Grafana

Request path (K8s)

  • / → Ingress → Frontend Service → UI pods
  • /api → Ingress → Backend Service → API pods
  • Backend → Postgres Service
  • ServiceMonitor / scrape job → Prometheus

Local path (Compose)

  • Browser :3000 → Nginx → proxies /api
  • Backend :8000 → Postgres :5432
  • Optional Prom :9091 · Grafana :3300

ClinicFlow Capstone8 / 16
07 · DevSecOps

Trivy as a hard quality gate

Policy in CI

  • Scan both container images
  • --severity HIGH,CRITICAL
  • --ignore-unfixed
  • --exit-code 1 → fail the job
  • No push to GHCR on findings

Real remediation example

  • First run failed on Starlette 0.41.3
  • CVEs: CVE-2025-62727, CVE-2026-48818, CVE-2026-54283
  • Fix: upgrade FastAPI → 0.143.2
  • Pulls Starlette ≥ 1.3.1
  • Pipeline returned to green
Security is a gate before registry publish — not a slideware checkbox.

ClinicFlow Capstone14 / 16
13 · Key learnings

What this project taught

Engineering

  • Fail closed on tests before images exist
  • Trivy turns CVEs into concrete upgrades
  • SHA tags beat floating latest
  • Helm + values keep env differences explicit
  • ServiceMonitor ties apps to Prometheus cleanly

Operations & craft

  • IaC must be destroyable, not just creatable
  • GitOps reduces “snowflake cluster” drift
  • Metrics need traffic — generate load to demo
  • Original domain + shared DevOps patterns
  • Evidence screenshots matter as much as code
